# How Senior Engineers Approach Unfamiliar Tech Stacks

Early-career engineers often feel overwhelmed when asked to work in a programming language or framework they've never seen before. Senior engineers rarely panic.

That confidence comes from understanding foundational computing primitives:
- Memory management: Is it garbage collected, reference counted, or RAII?
- Concurrency: Does it use threads, green threads, event loops, or actors?
- Error handling: Does it use exceptions, explicit Result types, or status codes?
- Type system: Is it dynamically typed, statically typed, structural, or nominal?

When picking up a new language like Rust, Go, or Elixir, senior developers look for how that language models state, I/O, and errors. Once the mental model is mapped, syntax is just something to look up in the docs.
