# Defending Multi-Agent Architectures Against Indirect Prompt Injection and Memory Poisoning

## Introduction to Adversarial Machine Learning in Agentic Systems
The move from isolated, single-turn large language model (LLM) interfaces to autonomous multi-agent architectures marks a major shift in artificial intelligence. Modern agentic systems handle complex workflows by breaking high-level goals into modular tasks, invoking external tools, consuming retrieved documents, and communicating across specialized agent nodes. Yet autonomous agents with persistent environmental access substantially expand the adversarial machine learning attack surface (Singh et al., 2026). Unlike classical machine learning systems that operate on closed, static distributions, agentic pipelines continuously ingest uncurated data from untrusted web endpoints, third-party application programming interfaces (APIs), shared vector stores, and peer agents (Chen et al., 2024; Singh, 2026).

The core vulnerability of autoregressive transformer architectures is the lack of a syntactic boundary between authoritative instructions and passive data payloads within context windows (Sharma, 2026). When untrusted inputs enter the reasoning loop, the model processes instruction and data tokens in an undifferentiated semantic space. Lin et al. (2025) classify these vulnerabilities as Prompt Trigger Attacks (PTA), a unified category that includes prompt injection, backdoor triggers, and adversarial manipulations intended to hijack model outputs.

In multi-agent and memory-enabled ecosystems, prompt manipulation can compromise multi-turn operations. Autonomous agents working within agreement frameworks must remain aligned with normative value systems and policy constraints throughout sequential decision-making (Holgado-Sánchez et al., 2026). Retrieval-augmented generation (RAG) and persistent memory mechanisms, including episodic vector databases and shared scratchpads, expose workflows to indirect prompt injection and long-term memory poisoning (Bhatnagar, 2026; Louck, 2026; Singh, 2026). Securing these architectures requires rigorous threat modeling, structural containment, cryptographic boundary enforcement, and origin-bound information-flow controls.

## Mechanisms of Indirect Prompt Injection and Memory Poisoning
Formalizing untrusted data ingestion in multi-agent workflows requires clear definitions of ingestion pathways, attacker capabilities, and structural failure modes across execution stages. In an agentic network, adversaries do not need direct prompt access. Indirect prompt injection occurs when adversarial control sequences are embedded in external data sources, including retrieved web pages, unstructured files, database records, and inter-agent messages (Chen et al., 2024; Singh, 2026). When an ingestion agent retrieves or parses such a payload, embedded instructions can hijack the context window, override developer instructions, trigger unauthorized API actions, exfiltrate private context, or divert execution trajectories (Chen et al., 2024; Sharma, 2026).

Transient injections target immediate policy violations in the active forward pass. Episodic memory architectures add a persistent attack surface known as Prompt Persistence Attacks (Bhatnagar, 2026). In persistent agent systems, episodic vector databases and scratchpads retain interaction histories, tool outputs, and synthesized observations across sessions. Bhatnagar (2026) shows that adversaries can exploit memory retention through incremental, sub-threshold poisoning. Instead of injecting overt jailbreaks that trigger input classifiers, they introduce subtle, benign-appearing factual distortions or biased instructions across sequential interactions. Over time, these changes shape persistent memory, bias future reasoning, distort decision-making, and subvert alignment guarantees without violating explicit safety constraints (Bhatnagar, 2026).

A critical weakness in persistent memory pipelines is the malleability of authority signals across the memory write-retrieve-act lifecycle (Louck, 2026). Conventional agent defenses assess a retrieved memory item's authority to steer consequential actions, such as payments or system configuration changes, through content trust-scoring or lineage tracking. Louck (2026) proves that adversaries can systematically launder untrusted origins into trusted states through three agent-specific channels:

1. *Agent Summarization*: When an agent compresses or summarizes untrusted context containing malicious directives, the resulting memory is attributed to the agent itself, stripping untrusted provenance (Louck, 2026).
2. *Trusted-Tool Echoing*: An attacker induces a trusted tool, such as a database query or calculator, to echo malicious instructions, giving the payload the tool's trust rating (Louck, 2026).
3. *Manufactured Corroboration*: The adversary introduces multiple untrusted entries across distinct sessions that corroborate a malicious premise, tricking heuristic lineage checks into elevating credibility (Louck, 2026).

These laundering channels break or invert derivation edges, making content- and lineage-based defenses fundamentally unsound (Louck, 2026).

## Architectural and Cryptographic Defense Paradigms
Mitigating indirect prompt injection and memory corruption calls for layered defenses that combine cryptographic encapsulation, graph-structured reachability analysis, non-malleable authority tracking, and preference optimization.

To address the lack of syntactic instruction-data separation, Sharma (2026) introduces a containment architecture designed to make injection attempts structurally inert. The architecture has four layers:

1. *Ephemeral Cryptographic Token Generation*: Provides 256 bits of boundary entropy to prevent delimiter prediction (Sharma, 2026).
2. *Input Canonicalization*: Pre-processes untrusted input to eliminate encoding bypasses and delimiter smuggling (Sharma, 2026).
3. *Token-Authenticated XML Envelopes*: Wraps untrusted data with server-side escape validation (Sharma, 2026).
4. *Behavioral Prompt Grounding*: Conditions the model to treat enclosed content strictly as passive data (Sharma, 2026).

Under a black-box model without runtime oracle access, the probability of crafting a valid boundary escape is cryptographically negligible ($P \le 2^{-256}$) (Sharma, 2026).

Singh (2026) developed GraphShield to protect multi-agent and RAG workflows from context-borne privilege escalation. GraphShield represents system prompts, retrieved knowledge, agent nodes, and parsed instructions as a directed Trust-Knowledge Graph (TKG). It frames security as a structural reachability problem: whether an untrusted instruction node can reach a policy-enforcement node within a trust-threshold subgraph (Singh, 2026). GraphShield uses typed instruction-violation signatures that assign zero trust to pattern-matched attacks, together with provenance filtering for retrieved and agent-supplied content (Singh, 2026). Benign instructions receive bridge trust, allowing the trust threshold to serve as a structural reachability gate across multi-agent hops (Singh, 2026).

To counter memory laundering, Louck (2026) formalizes memory security with machine-checked TLA+ proofs. The work establishes a three-part separation theorem: no content- or lineage-based defense is sound under laundering ($T_1$), write-time origin binding is necessary ($T_2$), and non-malleable origin-bound authority with Sybil-resistant corroboration gating is sufficient ($T_3$). This is instantiated in the Tamper-evident Memory Authority, Non-Malleable (TMA-NM) framework, which enforces non-malleable information-flow control (IFC) across the write-retrieve-act pipeline and prevents untrusted memories from gaining execution authority (Louck, 2026).

Post-training alignment can reinforce the model's internal instruction hierarchy. Chen et al. (2024) introduce SecAlign, which applies preference optimization to datasets pairing prompt-injected inputs with secure completions that execute developer instructions and insecure completions that follow injections. The approach teaches LLMs to prioritize authoritative instructions over untrusted context (Chen et al., 2024). Lin et al. (2025) propose UniGuardian, which detects Prompt Trigger Attacks using a single-forward-pass strategy. By combining detection and text generation in one forward pass, UniGuardian avoids the latency overhead of dual-LLM sandwiching and secondary guardrail verifiers (Lin et al., 2025). Learning value-grounding functions through multi-objective Markov decision processes also helps multi-agent agreement protocols remain aligned with normative values (Holgado-Sánchez et al., 2026; Singh et al., 2026).

## Evaluation of Defensive Trade-offs: Latency, Cost, and Utility
Multi-agent defenses must balance security guarantees against runtime latency, compute cost, and task utility. Traditional mitigation techniques, including dual-LLM sandwiching, secondary classification filters, and iterative prompt wrapping, impose substantial latency penalties, increase API costs, and degrade reasoning utility.

Recent architectural defenses offer stronger trade-offs:

- *Containment and Latency*: Sharma's (2026) cryptographic boundary architecture achieved a 94.3% syntactic containment rate across 547 adversarial patterns from Garak, OWASP LLM Top 10, HarmBench, and multilingual probe sets, with under 0.5 ms runtime overhead per request. The 5.7% residual failures were model-level semantic jailbreaks orthogonal to syntactic boundary containment (Sharma, 2026).
- *Cross-Model Structural Robustness*: Evaluated across four benchmarks (PromptBench, INJECAGENT, RAGInject-Bench, MultiAgentEscape-Bench) and three victim models (Qwen2-0.5B, Gemma3-4B, Llama3.2), GraphShield achieved a block-level $F_1$ score of 0.791. Its performance was invariant across models because of structural reachability gating (Singh, 2026).
- *Elimination of Memory Laundering Vulnerabilities*: Louck (2026) showed that existing content and lineage defenses suffer attack success rates (ASR) up to 68% under laundering channels across eight frontier models. TMA-NM, by contrast, achieved 0% ASR against direct and laundering attacks while preserving 100% legitimate utility (Louck, 2026).
- *Alignment Robustness and Utility*: SecAlign reduced prompt injection success rates to below 10% on sophisticated attacks while maintaining benign task utility comparable to unaligned baselines (Chen et al., 2024). UniGuardian provides unified trigger detection in a single forward pass, eliminating secondary invocation costs (Lin et al., 2025).

## Open Security Challenges
Securing multi-agent architectures against indirect prompt injection and episodic memory poisoning requires layered defenses. Effective protection combines cryptographic boundary containment (Sharma, 2026), graph-structured taint reachability gating (Singh, 2026), non-malleable origin-bound authority control (Louck, 2026), preference optimization for instruction hierarchy (Chen et al., 2024), and single-forward trigger detection (Lin et al., 2025).

Several challenges remain. Cryptographic envelopes provide robust syntactic containment, yet semantic jailbreaks that manipulate reasoning without escaping boundaries require deeper cognitive validation (Sharma, 2026). Detecting subtle Prompt Persistence Attacks in decentralized episodic memory stores also demands Sybil-resistant temporal anomaly detection (Bhatnagar, 2026; Louck, 2026). Maintaining value alignment and preventing policy drift in open multi-agent agreement systems under adversarial conditions remains an active research frontier (Holgado-Sánchez et al., 2026; Singh et al., 2026).
