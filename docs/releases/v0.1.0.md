# HowlWriter v0.1.0

## What it is
HowlWriter is a writing, editing, humanization, research, citation,
provenance, and verification system built to work with HowlPlane.

## Release artifact
`howlwriter-0.1.0-py3-none-any.whl` -- a pure-Python wheel, checksummed in
`SHA256SUMS`. The core install (`pip install howlwriter`) needs only PyYAML
and gives you every subcommand except `ui`, which needs the optional `web`
extra (`pip install "howlwriter[web]"`) for its FastAPI/uvicorn server; the
frontend's built static assets ship inside the wheel itself.

## Verification
`howlwriter --version` and every subcommand's `--help` work with just the
core install. `howlwriter ui` reports a clean, actionable error (not a
traceback) if the `web` extra isn't installed.
